# Blurb website

Public website, user guide, privacy policy and support for Blurb.

- [Website](https://swimxd.github.io/blurb-website/)
- [User guide](https://swimxd.github.io/blurb-website/guide.html)
- [Privacy](https://swimxd.github.io/blurb-website/privacy.html)
- [Support](https://swimxd.github.io/blurb-website/support.html)

Plain HTML and CSS; GitHub Pages publishes main from the repository root. Keep guide instructions aligned with the distributed app version. This repository does not host app source, build instructions, private diagnostics or APK downloads.

Content aligned with the current Blurb beta as of September 23, 2026 (1.3.18). The site covers Google Messages free access, the shared ten-summary preview, the one-time Pro unlock, WhatsApp/Telegram support, opt-in original-message expansion, the cloud fallback suggestion and background battery guidance. The guide identifies beta behavior, including the usage diagnostics control and its defaults. Session replays were removed from the app. The privacy policy is a short summary kept in sync with the app's copy (`app/src/main/assets/privacy-policy.txt` in the app repository). Verify user-facing labels and behavior against the app implementation when updating these pages.
