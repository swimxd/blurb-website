# Blurb website

Public website, user guide, privacy policy and support for Blurb.

- [Website](https://swimxd.github.io/blurb-website/)
- [User guide](https://swimxd.github.io/blurb-website/guide.html)
- [Privacy](https://swimxd.github.io/blurb-website/privacy.html)
- [Support](https://swimxd.github.io/blurb-website/support.html)

Plain HTML and CSS; GitHub Pages publishes main from the repository root. Keep guide instructions aligned with the distributed app version. This repository does not host app source, build instructions, private diagnostics or APK downloads.

Content aligned with the current Blurb beta as of September 23, 2026 (1.3.18). The site covers Google Messages free access, the shared ten-summary preview, the one-time Pro unlock, WhatsApp/Telegram support, opt-in original-message expansion, the cloud fallback suggestion and background battery guidance. The guide and privacy policy explicitly identify beta behavior, including independent diagnostics/replay controls and their different defaults. Verify user-facing labels and behavior against the app implementation when updating these pages.
