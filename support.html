Reports open on GitHub and require a GitHub account. They are public.

Do not include private messages, API keys, purchase tokens, receipts or personal details. Use fictional examples and check screenshots before sharing.

Purchases and background summaries

For Pro, try Restore purchase in Settings → Blurb Pro using the Google Play account that bought it. Pro is a one-time unlock; cloud API charges are separate. See the Pro guide for preview and payment details.

If summaries stop when Blurb is closed, use the background battery note or Settings → Background activity. See troubleshooting for phone-specific guidance.

Private privacy questions

Email blurbapp.support@gmail.com for support or private privacy questions. Do not post sensitive privacy requests in public issues.
